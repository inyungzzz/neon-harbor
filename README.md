# 霓虹港｜城市行動原型

一款原創的開放世界城市互動故事 Web 原型。純 HTML、CSS 與 JavaScript，無需建置工具，可直接在瀏覽器開啟 `index.html`。

## 本機預覽

用瀏覽器開啟 `index.html`，或在專案目錄啟動任意靜態檔案伺服器。

## GitHub Pages 部署

此專案包含 `.github/workflows/pages.yml`。將程式碼推送到 `main` 分支後，GitHub Actions 會自動發布網站。

第一次部署前，請在 GitHub 專案設定中開啟 **Settings → Pages → Build and deployment → Source: GitHub Actions**。部署完成後，可在同一頁取得網站網址。

玩家狀態會儲存在目前瀏覽器的 `localStorage` 中。

## 操作方式

- 使用方向鍵或 `W`、`A`、`S`、`D` 移動地圖上的角色。
- 也可以點地圖旁的方向按鈕，適合觸控螢幕。
- 移動到右上角的委託標記後，按 `Enter` 或點「前往委託」查看任務。
- 靠近起點的車輛時按 `E` 上車；駕車時每次移動兩格，再按 `E` 下車。
- 高風險任務會增加警方熱度；使用「躲避巡查」可逐級降低熱度。
- 警方熱度需回到港區入口安全點，花 30 分鐘才能降低 1 級。
- 五顆星顯示目前警方關注程度；位置、車輛與任務狀態會儲存在目前瀏覽器。
- 依序完成三份委託；每個選擇都會改變報酬、名聲或警方熱度。
- 完成主線間隙可重玩「港區兜風挑戰」；報名費 $100，路線選擇會影響獎勵和警方熱度。
- 地圖上有三枚可收集的港灣印記；每枚可獲得 $150 與 2 點名聲，開車經過也會自動拾取。
- 在阿哲的車庫花 $900 購買引擎調校，可永久提升駕車速度；現金不足時不能購買。
- 車庫升級與活動獎勵會反映在現金狀態；升級完成後駕駛速度會提高到每次 3 格。
- 委託能增加阿哲或小葵的信任；信任達 2 點可解鎖引擎優惠或兜風挑戰免報名費。
- 探索、任務與挑戰會推進遊戲時間；白天與夜間使用不同的城市色調。
- 主線委託需先在地圖移動到標記，再按 `Enter` 或點「接取委託」；後續委託會出現在不同街區座標。
- 「一路上的選擇」會保存任務選項、結果與完成時間，並顯示最近 50 份委託；讀取舊版存檔時會自動補上歷程欄位。
- 主線現有四份委託；完成河岸市集協力後會顯示本章完成，沿途分支會影響人脈、報酬與警方熱度。
- 最後一份委託會依你建立的人脈與累積的警方熱度，呈現不同的章節收尾回響。
- 重設進度前會顯示確認提示；確認後只會清除霓虹港自己的瀏覽器存檔。
