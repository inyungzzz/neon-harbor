# GTA 7 Web 應用計畫

## 願景

製作一款發布於 GitHub Pages 的原創 Web 互動體驗「霓虹港（Neon Harbor）」，採用現代開放世界城市冒險題材，讓玩家在有生活感的港口城市中探索、接案、做選擇，並看見行動對資源與街區人脈造成的影響。「GTA 7」是最初構想時的暫稱，不是作品名稱。

本專案以 Web 應用為目標，不以製作大型 3D 遊戲為範圍。玩法與呈現方式應保有原創性：可借鑑開放世界犯罪遊戲的類型特色，但角色、城市、故事、美術與具體內容都需要自行創作。

## 核心玩法構想

主要遊戲循環：

> 探索城市 → 發現機會 → 接受任務 → 執行計畫 → 應對後果 → 解鎖新區域與人脈

任務可提供多種處理方式，例如正面行動、潛行、談判、利用環境或尋求同伴協助。完成方式可能影響報酬、風險、角色關係及後續可接觸的任務。

預計的核心系統：

- **城市探索：** 不同區域、日夜變化、街區活動；以步行、駕車或大眾運輸作為探索方式的概念。
- **任務與自由行動：** 主線故事、支線委託、競速、收集、社交活動及隨機事件。
- **計畫與執行：** 重要任務可先蒐集情報、挑選裝備與隊友，再依情況調整策略。
- **通緝與熱度：** 犯罪行動會增加警方注意；逃離現場、降低辨識度或避風頭會影響後續風險。
- **資源與人脈：** 賺取資金、改善藏身處、取得載具與工具，並培養能解鎖支援的角色關係。
- **分支後果：** 關鍵選擇影響任務走向、盟友態度與城市局勢。

## 產品形式與初始範圍

- 交付形式：可在瀏覽器執行的 Web 應用，專案可提交至 GitHub。
- 建議先完成可玩的文字／介面原型，不先追求大型 3D 城市。
- 初始原型構想：城市首頁、任務列表、文字事件與選項，以及資金／名聲等狀態顯示。
- 第一個任務流程構想：接案 → 踩點 → 選擇進入方式 → 完成目標 → 逃離現場 → 顯示結果與狀態變化。
- 技術選型、視覺方向、角色與城市設定尚未決定。
